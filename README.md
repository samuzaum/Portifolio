# Samuel Louvera - Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória, formação, experiências, tecnologias e projetos.

## Sobre

O site foi criado como uma página estática responsiva, com foco em uma apresentação objetiva para oportunidades acadêmicas e profissionais.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Devicon
- GitHub Pages

## Estrutura

- `index.html` - página principal do portfólio
- `style.css` - estilos globais e responsividade
- `assets/images` - imagens gerais e favicon
- `assets/documents` - documentos e currículos
- `assets/projects` - imagens relacionadas aos projetos
- `assets/js` - scripts de interação da página

## Conteudo

O portfolio apresenta:

- resumo profissional
- formação acadêmica
- experiências
- tecnologias
- projetos
- contatos profissionais

## Status

Em evolução, com ajustes de conteúdo, currículo e apresentação dos projetos em andamento.
